## 🏛️ Visão Geral

O **Herbário Filogenético das Línguas do Mundo** é uma aplicação web autônoma concebida sob a estética *Organic / Biophilic / Solarpunk*, dedicada à exploração genealógica, tipológica e biogeográfica da diversidade linguística humana.

A aplicação unifica três perspectivas complementares da história da linguagem:
1. **🌍 Globo 3D Ortográfico:** Projeção esférica tridimensional com recorte cartográfico opaco (sem transparência de hemisfério traseiro), mapeando o berço ancestral (*Urheimat*) das 21 macrofamílias e seus arcos geodésicos de dispersão histórica com base em dados do *Natural Earth 110m*.
2. **🏛️ Dossel das Macrofamílias:** Painel estrutural comparativo com cards dinâmicos que apresentam a cronologia, ecologia, contagem de línguas vivas, extintas (†) e protolínguas, além de filtros interativos em tempo real.
3. **🌿 Árvore Filogenética Viva:** Motor gráfico vetorial baseado em curvas de Bézier dinâmicas e condução de "seiva ancestral" (*sap-flow*), permitindo navegar por 580 nós entre línguas naturais, dialetos, ramificações intermediárias e formas reconstruídas.
4. **📖 Dossiê Herbário (Specimen Drawer):** Gaveta lateral com ficha técnica individualizada para cada língua, contendo linhagem ancestral completa, endônimo nativo, estimativa de falantes, ordem básica de constituintes (SVO/SOV/VSO), alinhamento morfossintático e fontes acadêmicas.

## 💻 Arquitetura Técnica e Estrutura de Diretórios

A aplicação foi projetada para ter **zero dependências externas em tempo de execução**, operando de forma 100% autônoma via protocolo `file://` ou em servidores de arquivos estáticos simples (GitHub Pages, Cloudflare Pages, Nginx):

```
linguistica/
├── index.html                   # Artefato de produção (GitHub Pages)
├── arvore_interativa.html       # Artefato local autônomo equivalente
├── CNAME                        # Apontamento de domínio personalizado (linguas.dan.seg.br)
├── LICENSE                      # Licença MIT
├── README.md                    # Documentação técnica e científica do projeto
│
├── docs/                        # Documentação Técnica e Acadêmica
│   ├── architecture/            # Arquitetura e Decisões de Design (ARCHITECTURE.md)
│   └── references/              # Referências Bibliográficas, Glotocronologia e Metodologia (BIBLIOGRAPHY.md)
│
├── src/                         # Código-Fonte Modular
│   ├── assets/                  # Dependências empacotadas (D3.js v7, GeoJSON Natural Earth)
│   ├── data/                    # Modelos biogeográficos, XML Drawio e grafo de 580 nós
│   ├── generators/              # Scripts geradores setoriais das árvores filogenéticas
│   └── templates/               # Templates HTML, design tokens CSS e scripts de renderização
│
├── tools/                       # Compilação e Testes
│   ├── build.py                 # Compilador principal unificado
│   └── test_phase2_qa.py        # Suíte de testes automatizados de integridade e grafos
│
└── legacy/                      # Artefatos legados preservados para histórico de versões
```

Consulte a documentação aprofundada em:
- [🏛️ Arquitetura do Sistema (`docs/architecture/ARCHITECTURE.md`)](docs/architecture/ARCHITECTURE.md)
- [📚 Corpus Bibliográfico e Glotocronologia (`docs/references/BIBLIOGRAPHY.md`)](docs/references/BIBLIOGRAPHY.md)

### Principais Inovações Técnicas:
* **Recorte Cartográfico Esférico Real:** A verificação angular `d3.geoDistance(center, [lon, lat]) <= Math.PI / 2` garante que marcadores e dispersões do hemisfério traseiro sejam estritamente suprimidos, eliminando a projeção indevida de línguas sobre oceanos opostos.
* **Layout Tidy Tree Adaptativo:** Algoritmo que calcula recursivamente as alturas e distâncias dos nós para prevenir sobreposições nas ramificações densas.
* **Filtros Reativos Cruzados:** Filtragem em tempo real por status (*Todas*, *Vivas*, *Extintas †*, *Protolínguas*) atuando de forma síncrona no Globo (atenuação de pinos de troncos sem representantes), no Dossel (desativação de cards) e na Árvore Viva.
* **Responsividade Completa:** Breakpoints dedicados para visualização desktop e mobile (<768px), com suporte nativo a eventos de toque (`touchstart`/`touchmove`) para rotação do globo e pan/zoom da árvore.

## 🛠️ Como Compilar Localmente

Para recompilar a aplicação a partir do código-fonte:

```bash
# 1. Certifique-se de possuir Python 3.8+ instalado
python3 --version

# 2. Execute o compilador que gera simultaneamente arvore_interativa.html e index.html
python3 tools/build.py

# 3. Execute a suíte de testes de validação automatizada de QA
python3 tools/test_phase2_qa.py

# 4. Abra diretamente no navegador
xdg-open index.html
```
